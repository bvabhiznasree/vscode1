# MelodyHub Music Streaming App

## Requirements covered
- Admin Module and User Module
- Signup/Login using browser Local Storage
- HTML, CSS and JavaScript only
- CSS Grid and Flexbox UI
- JavaScript navigation
- Search and genre filtering
- Favorites and playlists
- Music player interface
- Admin dashboard
- Add/delete songs
- User management
- Responsive design

## Run
Open `index.html` in a browser. No backend or database is required.

Admin demo:
- Email: admin@melodyhub.com
- Password: admin123

## Real audio
The included app has a music-player interface. To play actual local audio, put an MP3 file in `songs/` and add a `file` property to a song in `script.js`, for example:
`file:"songs/my-song.mp3"`
