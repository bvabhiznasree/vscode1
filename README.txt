RaagaVibe React version

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost URL printed in the terminal.

This is a front-end demo. Login/signup is local browser-only. Audio uses public sample streams, not actual Telugu movie recordings. Lyrics are original demo lines. Replace with content you own or are licensed to use.
